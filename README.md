# CS336 Assignments Restart

This repository contains independent restarts of the five CS336 assignments.
Each assignment owns its implementation, experiments, and writeup:

```text
CS336-new/
├── assignment1-basics/
│   ├── cs336_basics/
│   ├── tests/
│   └── writeup/
├── assignment2-*/
├── assignment3-*/
├── assignment4-*/
└── assignment5-*/
```

The Assignment 1 writeup is in `assignment1-basics/writeup/`. Its 17 problem
directories each contain a `question.typ` and a separate `answer.typ`, so the
original prompts remain unchanged while answers and figures can be added
incrementally.
